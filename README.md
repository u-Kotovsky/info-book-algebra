# Дипломный проект: Информационная система по школьному предмету "Алгебра"

## 1. Описание проекта
Данный проект предназначен для простого изучения тем по школькому предмету "Алгебра" из одного приложения.

Тип работы: Выпускная квалификационная работа (дипломный проект)

---

## 2. Цель и задачи проекта
**Цель:** разработка информационной системы

**Задачи:**
- анализ предметной области
- разработка архитектуры системы
- реализация программного решения
- тестирование и оценка эффективности

**Область применения:** обучение

---

## 3. Функциональность
- мониторинг параметров системы
- обработка данных
- визуализация результатов
- управление процессом

**Ограничения:**
- ограниченная масштабируемость
- тестовый режим эксплуатации

---

## 4. Архитектура проекта
Тип архитектуры: клиент

**Технологии:**
- C#
- PostgreSQL

**Структура проекта:**
- `docs/` — документация
- `InfoBookAlgebra/` — WPF приложение
- `InfoBookAlgebra.Core/` — ядро для приложения
- `InfoBookAlgebra.Tests/` — тесты

---

## 5. Установка и запуск

**Требования:**
- .NET 8+

**Установка:**
```bash
git clone https://github.com/u-Kotovsky/info-book-algebra.git
cd info-book-algebra
```

**Запуск:**
```bash
dotnet build
```

---

## 6. Использование
После запуска системы пользователь может:
- просматривать список тем
- выбирать тему
- анализировать выбранную тему
